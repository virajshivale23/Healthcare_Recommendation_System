## 📌 Project Overview

The Personalized Healthcare & Medicine Recommendation System is an AI-powered web application that predicts diseases based on user symptoms and provides personalized healthcare recommendations.

The system leverages Machine Learning algorithms to analyze symptoms entered by the user and generates meaningful recommendations including:

- Disease Prediction
- Medicine Suggestions
- Precautions
- Diet Recommendations
- Workout Recommendations
- Doctor Consultation Advice

The project is designed with a modern and responsive user interface using Flask, HTML, CSS, and JavaScript.

---

# 🎯 Problem Statement

Many individuals struggle to identify possible diseases from their symptoms and often rely on unreliable internet sources.

This project aims to provide an intelligent healthcare assistant capable of:

- Predicting probable diseases
- Providing first-level healthcare recommendations
- Suggesting medicines
- Recommending healthy diets
- Advising precautions
- Encouraging users to consult healthcare professionals

**Note:** This application is intended for educational purposes and preliminary health guidance only. It is not a substitute for professional medical advice.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/virajshivale23/Healthcare_Recommendation_System.git
```

Move inside the project

```bash
cd Healthcare_Recommendation_System
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Flask

```bash
python app.py
```

Open browser

```
http://127.0.0.1:5000
```
